배우기

이 책을 읽는 법

이 책은 돌려 보는 교과서다. 영상도 PDF 도 아니다 — 모든 예제가 이 탭에서, 당신의 GPU 로 실행되고, 돌리기 전에 고칠 수 있다. 핵심은 이렇다: 설명 옆에 있으나 돌아가지 않는 코드는 그림일 뿐이다. 여기서는 눌러 보면 진짜로 돈다.

모든 것이 돈다, 두 언어로

각 예제는 Run 버튼이 있는 상자에 들어 있고(⌘/Ctrl + Enter 도 된다), 돌리기 전에 코드를 고칠 수 있다. 대부분의 상자는 탭 둘을 든다 — JavaScript 판과 Python 판, 같은 일을 각각 — 그래서 "값이 같다"를 믿는 대신 둘 다 눌러 수를 비교할 수 있다. GPU 에서 값을 읽는 것은 JavaScript 에서는 await 다(await x.item()); Python 은 바로 읽는다.

진도는 당신의 것

코스 홈에서 각 레슨 앞에는 동그라미가 있다. 그것을 눌러 레슨을 체크하거나, 레슨의 직접 연습이 대신하게 두면 된다 — 당신의 수정이 페이지에 learned 를 띄우면 그 레슨은 표시된다. 진도는 이 브라우저에만 남는다: 계정도, 업로드도 없고, 사이트 데이터를 지우면 언제든 초기화된다.

경로

레슨은 트리를 이루고, 본선은 의존 순서로 흐른다: 기초 수학(수학을 직접 돌린다 — 벡터에서 연쇄법칙까지) → 딥러닝 기초(텐서에서 학습 루프까지) → 실전 깊이(진짜 망·데이터·디버깅) → 시퀀스와 트랜스포머, 그리고 곁에 논문 사례와 끝에 캡스톤. borch 가 처음이면 위에서부터 걷고, 아니면 필요한 곳으로 건너뛰어라 — 각 레슨은 무엇에 기대는지 밝힌다.

필요한 것

  • WebGPU 가 되는 브라우저. 없으면 페이지가 그렇게 분명히 말한다 — 더 느린 것으로 내려가 시치미 떼지 않는다.
  • 그 밖에는 없다 — 설치도, 계정도, 서버도.

레슨이 쓰는 기호와 약칭은 표기법 페이지에 모아 뒀다; 낯선 표기를 만나면 언제든 그리로 돌아가라.
