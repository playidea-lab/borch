LoRA: 저랭크 어댑터

LoRA — Low-Rank Adaptation (Hu et al., 2021) — 는 크고 학습된 층을 얼리고 그 옆에 작은 저랭크 행렬 한 쌍을 학습한다. 전체 파인튜닝의 대부분을 학습 파라미터의 일부만으로 얻고, 어댑터는 따로 실어 보낼 수 있는 KB 크기의 것이 된다. 이건 borch.peft 에 있다 — torch 에는 없는 네임스페이스다.

이 레슨은 borch.ts 전용이다. 나머지 Learn 과 달리 Python 탭이 없다: borch.peft 는 borch.ts 에 먼저 들어왔고, numpy 코어와 Python 바인딩은 전이학습 방향이 빌드를 정당화할 때 이를 반영한다. 그 분리는 조용히 두지 않고 peft.ts 에 적어 뒀다.

얼린 base 옆의 값싼 어댑터

LoRALinear 는 얼린 base 가중치(버퍼, parameters() 밖)와 랭크 r 의 학습 쌍 A·B 를 든다. B 는 0 에서 시작하므로, 학습 전에는 층이 정확히 base 그 자체다.

어댑터만 학습

layer.parameters() 를 옵티마이저에 넘기면 A 와 B 만 건드린다. 여기 타깃은 base 자신의 출력에 작은 선형 이동을 더한 것 — 완전 랭크 어댑터가 도달할 수 있는 것 — 이고, base 가중치는 얼려 있으므로 끝나도 그대로다.

추론을 위해 다시 접기

학습된 어댑터는 base 옆의 두 행렬이다. merge() 는 그것을 하나의 평범한 Linear 로 접는다 — W' = W + (alpha/r)·B·A — 그래서 추론과 ONNX 내보내기는 어댑터 가지 없이 평범한 층 하나만 본다.

직접: 어댑터에 학습률 주기

아래 층은 얼린 base 를 적응시켜 직선 y = 3x 를 배워야 하지만, 스텝 크기가 0 인 동안은 움직이지 못한다. 진짜 학습률을 넣으면 어댑터가 그것을 잡았을 때 페이지가 말해 준다.

위 블록이 에러를 내면, 그것도 알아둘 값이다. 이 페이지의 모든 예제는 테스트가 도는 그 라이브러리를 상대로 돈다 — 스크린샷이 아니다. 되돌리려면 Reset 을 누른다.
