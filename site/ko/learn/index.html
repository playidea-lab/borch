배우기

러닝 트리, 전부 도는 것

모든 블록은 두 번 쓰여 있다 — JavaScript 탭과 Python 탭, 같은 일을 각각. 대부분 JavaScript 로 열려 한 번 눌러 바꾸고, 몇 개는 Python 으로 열린다. Playground 도 둘 다 받는다.

이 페이지들의 모든 코드 블록은 이 탭에서, 당신의 GPU 에서 돈다. 돌리기 전에 고쳐도 된다. 설치하는 것도 올려 보내는 것도 없다. borch 가 처음이면 트리를 위에서부터 걸어도 되고, 아무 레슨의 동그라미를 눌러 체크해 둬도 된다 — 진도는 이 브라우저에 남고, 계정은 없다.

처음이신가요? 이 책을 읽는 법부터 보고, 표기법 가이드를 곁에 두세요.

텐서에서 시작하거나 프로젝트 튜토리얼로 건너뛴다. (대화형 코스 지도는 JavaScript 가 필요하고, 이 두 링크는 아니다.)

필요한 것

  • WebGPU 가 되는 브라우저. 없으면 페이지가 그렇게 말한다 — 조용히 더 느린 것으로 내려가지 않는다.
  • 그 밖에는 없다. 설치도, 계정도, 서버도.

이 페이지들을 어떻게 안 썩게 하는가

안 돌리는 예제는 썩고, 그것을 처음 아는 사람은 읽는 사람이다. 여기 있는 것은 전부 테스트가 도는 그 라이브러리를 부른다 — 이름이 바뀌면 이 페이지가 눈에 보이는 자리에서 깨진다.

읽기보다 만들어 보고 싶으면 튜토리얼이 문제 하나를 끝까지 가져간다 — 같은 내용이 개념이 서로 기대는 순서가 아니라 프로젝트가 필요로 하는 순서로 온다.

이 프로젝트가 하는 주장은 좁고 실측된 것이다: 입문 튜토리얼 코드가 임포트만 바꿔 같은 값을 낸다. 그 근거가 되는 수는 첫 화면에 있고, 일부러 없는 것도 거기 적혀 있다.
