이 탭 안의 JupyterLite 이고, 선반에 pyborch 가 미리 올라가 있다. 커널은 워커 안의 Python(Pyodide) 이고, import borch_webgpu as torch 가 이 탭의 GPU 에서 borch.ts 를 띄운다. CUDA 도, 기계에 깐 Python 도, 계정도 없다.

두 줄

%pip install pyborch
import borch_webgpu as torch

같은 두 줄이 어느 Pyodide 에서든 된다 — 직접 띄운 JupyterLite, PyScript, marimo 의 wasm 판. wheel 이 borch.ts 를 안에 지니고 import 때 장치를 띄우기 때문이다. torch 코드에서 바뀌는 것은 Python 페이지에 있다 — 짧다.

탭이 못 하는 것

  • 메모리는 탭의 것, 몇 GB. 데이터셋과 사전학습 가중치는 매번 다운로드다.
  • 패키지는 Pyodide 의 것: CUDA 계열은 없고, 일부 C 확장도 없다.
  • 긴 학습은 커널을 붙잡는다. 노트북이 원래 그렇다.
  • NVIDIA 카드를 단 리눅스는 Chrome 플래그 둘이 필요하다 — GPU 페이지에 있다.
