LoRA: low-rank adapters

LoRA — Low-Rank Adaptation (Hu et al., 2021) — freezes a big trained layer and trains a tiny low-rank pair of matrices beside it. You get most of full fine-tuning for a fraction of the trainable parameters, and the adapter is a KB-sized thing you can ship on its own. It lives in borch.peft — a namespace torch does not have.

This lesson is borch.ts only. Unlike the rest of Learn there is no Python tab: borch.peft lands in borch.ts first, and the numpy core and the Python binding mirror it when the transfer-learning direction earns the build. That split is written down in peft.ts rather than left silent.

A cheap adapter beside a frozen base

A LoRALinear holds a frozen base weight (a buffer, out of parameters()) and a trainable pair A·B of rank r. B starts at zero, so before any training the layer is exactly its base.

Train only the adapter

Hand layer.parameters() to an optimiser and it touches only A and B. Here the target is the base's own output plus a small linear shift — something a full-rank adapter can reach — and the base weight is unchanged at the end because it is frozen.

Fold it back for inference

A trained adapter is two matrices sitting beside the base. merge() folds them into one plain Linear — W' = W + (alpha/r)·B·A — so inference and ONNX export see an ordinary layer, with no adapter branch left to run.

The layer below should learn the line y = 3x by adapting a frozen base — but it cannot move while the step size is zero. Set a real learning rate and the page says when the adapter has it.
