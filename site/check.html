Why this page exists

Every vendor claim in this repository has come from one laptop, and one of them was wrong for months: a 845 / 845 pass was written down as two vendors confirmed when the adapter had been google / swiftshader the whole time. The pass was real; the sentence about what it proved was not.

So the adapter is printed with the count, always, and in the same breath. A run that says google / swiftshader is also a real result — that is WebGPU's own CPU path and the values are still values. It just is not a statement about a GPU.

If you have a card this repository has never seen, this is the whole of what it takes to tell us: press the button and paste the first line into an issue.
