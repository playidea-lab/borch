Eigenvalues & the SVD

An eigenvector is a direction a matrix only stretches, never turns: A v = λ v. The singular value decomposition generalises that to any matrix, factoring it into a rotation, a scaling, and a rotation (A = U diag(S) Vᵀ) — the workhorse behind PCA, low-rank approximation and much else. Everything below runs in this page, in both languages.

Eigenvectors: the directions a matrix only stretches

For a symmetric matrix the eigenvalues are real and eigh returns them with their eigenvectors (as the columns of vectors). Take the first pair and check that A·v is just λ·v — same direction, scaled.

The SVD factors any matrix

A.svd() returns U, the singular values S, and V. Multiplying them back — U diag(S) Vᵀ — returns the original matrix, even though A is not square.
