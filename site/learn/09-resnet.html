Residual networks

Lesson 5 stacked convolutions. Stack enough of them and training stops working — not because the model is too small, but because almost nothing reaches the first layer. A residual network adds one line to each block, + x, and that line is the whole idea. Here you can measure what it carries.

The block

A BasicBlock is two convolutions and a way back. When the block changes the shape — more channels, or a stride that halves the image — the way back cannot be the input itself, so a 1×1 convolution reshapes it. When the shape is unchanged there is no shortcut layer at all: the tensor is added as it arrived.

What the shortcut carries

The argument for + x is usually drawn rather than measured. It does not have to be. Below, the same eight convolutions are stacked twice — once plainly, once with each layer's output added back to its input — and the gradient that reaches the first layer's weight is read out of both.

The two runs share a seed, so the layers start identical. Only the wiring differs.

The ratio is not a constant. It depends on the seed, the depth and the activation, and this page prints whatever this run produced rather than a number typed in once and left there. What survives the change of seed is the direction: the plain stack arrives small, the residual stack does not.

A small ResNet, trained

A stem, two blocks — one keeping the shape, one halving it — then pool, flatten and a linear head. That is the arrangement of every ResNet; a real one differs by repeating the middle, not by structure.

AdaptiveAvgPool2d is not here. torchvision's ResNet ends with it, so a line copied from there will not run; AvgPool2d with the feature-map size — 8 above — does the same thing when you know that size, which on a fixed input you do.

This sentence first said the absence was one the measured table counts. It is not — that table is about speed and agreement, and it has no row for this. What does hold the absence is tests/ts_axis.py, which compares the TypeScript surface against the numpy core and lists this name under no reason. Being counted and being explained are different things, and only the first of them was true here.

A ready-made ResNet18Cifar lives in the model catalogue, built from the same Conv2d and batch-norm layers as the block above — nothing in it is a special case the library knows about.
