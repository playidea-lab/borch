Watch a neural network learn

A classifier's whole job is to carve the input space into regions — one per class. For points on a plane you can see that carving. And you don't have to take my word for the figures below: each is a real network training in your browser, on your GPU, as you read. Press Run on any of them.

Two moons no straight line can split

Here are two interleaving half-moons, each a class. A linear model can only draw a straight boundary between them — and no straight line separates these. So we give the network one hidden layer with a non-linearity, and the boundary can bend. The grid below colours every point on the plane by the class the network would give it; the seam between the colours is the decision boundary. It starts as a random split and, over a hundred-odd steps, bends to fit.

That trained just now, in this tab — no server was called. It is a borch lesson; the whole thing is a few lines of PyTorch-shaped code you can read and edit in the frame.

The rate you train at decides everything

A network learns by stepping downhill on its error, and the step size — the learning rate — is the one knob that most often decides whether it learns at all. Too large and it diverges; too small and it crawls. The figure below trains the same small problem three times, changing only the rate. Each row of the heatmap is a run, left to right the steps, brightness the loss: one row stays bright (diverged), one goes dark (converged), one sits in between (too slow).

Why this reads better than a screenshot

Everything above is the point of borch: a PyTorch-shaped library that runs on WebGPU in the browser, so a demo of a model learning can live on a page and run for the reader — no server, no install, no sign-up. Each figure here is an <iframe>; you can put the same one on your own blog or docs with one line. Browse the widget gallery and copy any of them, or open the playground to write your own.
